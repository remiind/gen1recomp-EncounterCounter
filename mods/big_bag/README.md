# Big Bag

Gen 3 (Ruby, Sapphire, Emerald, FireRed, LeafGreen): every bag pocket and the
PC item storage hold up to 999 different items (option: 999 / 300 / 100).
Stack sizes stay as on the cartridge (99 per slot, 999 berries and PC).

A cartridge `.sav` export has the original fixed slot counts (Emerald: items
30, balls 16, TM/HM 64, berries 46, key items 30, PC 50). Slots beyond those
are left out of the export, so make room before exporting if the items matter.
Pal Park only moves Pokémon, so it is not affected.

Ships inside game.love of the fork's Windows and Android builds; it can be
switched off in the mod manager.
